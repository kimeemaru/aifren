# Synthetic Memory V2 diagnostics

These fixtures generate synthetic records and bounded expected outcomes. They are
not a source of product truth or personal character history. Test names and data
are illustrative; no private prepared seed or installed character is required.

Use the public structural test runner for cheap coverage. Scripts that explicitly
select a real provider can consume significant resources and require your own
configuration; never point them at a live character for mutation. Keep outputs
outside Git. Toy embeddings establish structural behavior only; run the separate
offline MiniLM check when the model is installed. Earlier shadow/evaluation modules
remain disconnected diagnostics, not an alternate normal memory authority.
